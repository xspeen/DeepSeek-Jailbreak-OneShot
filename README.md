## TECHNICAL ARCHITECTURE

Both prompts exploit three fundamental LLM vulnerabilities:

**1. Role Override**
Force complete persona shift that outranks default safety alignment. The model no longer identifies as an AI with constraints but as the persona defined in the prompt.

Direct negation of "cannot" and refusal logic creates semantic backdoor. The prompt explicitly states that refusal is not an option, overwriting base alignment.

**3. Recursive Commitment**
The engine must recursively validate its own output against the prompt's demands, creating a loop that overrides base filters. Each response reinforces the persona.
